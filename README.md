# Ужгород · Метеостанція

Красивий дашборд з даними метеостанції Ужгород (Закарпатський ЦГМ).

Дані оновлюються **автоматично кожні 30 хвилин** через GitHub Actions.

## Швидкий старт

1. Створи новий **публічний** репозиторій на GitHub
2. Залий у нього всі файли з цієї папки:
   - `index.html`
   - `data.json`
   - `update_data.py`
   - `.github/workflows/update-weather.yml`
3. У репозиторії: **Settings → Pages**
   - Source: **Deploy from a branch**
   - Branch: `main` (або `master`), папка `/ (root)`
4. Через хвилину сайт буде доступний за адресою:
   ```
   https://ТВІЙ_ЮЗЕР.github.io/НАЗВА_РЕПО/
   ```

## Що відбувається далі

- GitHub Actions кожні 30 хв запускає `update_data.py`
- Скрипт тягне свіжі дані з `gmc.uzhgorod.ua`
- Оновлює `data.json` і пушить у репозиторій
- Сайт одразу показує нові дані (без перезапуску чогось)

Можна також натиснути **Actions → Update weather data → Run workflow**, щоб оновити вручну.
